# Keyboard shortcuts

Press `?` in the editor to see this list in the app.

## Tables
| Key | Action |
|---|---|
| `T` | Add table |
| `Ctrl+Enter` | Add column to the selected table |
| `F2` | Rename selection |
| `Del` | Delete selection |
| `Ctrl+D` | Duplicate tables |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy, cut, paste tables |
| `Alt+↑` / `Alt+↓` | Move the selected column |
| Arrow keys | Nudge tables (Shift for bigger steps) |
| `N` | Add note at the pointer |

## Selection
| Key | Action |
|---|---|
| Click | Select a table, column or relationship |
| `Ctrl+Click` | Add or remove a table |
| `Shift+Drag` | Select tables in a box |
| `Ctrl+A` | Select all tables |
| `Esc` | Clear selection |

## View
| Key | Action |
|---|---|
| Drag canvas | Pan |
| `Ctrl+Scroll`, pinch | Zoom |
| `Ctrl+=` / `Ctrl+−` | Zoom in / out |
| `Ctrl+0` | Zoom to 100% |
| `Shift+1` | Fit entire schema |
| `Ctrl+Shift+L` | Auto layout |
| `Ctrl+K` | Search tables and columns |

## Window
| Key | Action |
|---|---|
| `F11` | Full screen |
| `Ctrl+Shift+/` or `Ctrl+\` | Hide or show the whole interface |
| `Ctrl+B` | Navigation pane |
| `Ctrl+Shift+T` | Toolbar |
| `Ctrl+.` | Inspector |
| `Ctrl+Shift+S` | Status bar |
| `M` | Minimap |
| `Ctrl+,` | Settings |

## General
| Key | Action |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+N` | New design or project |
| `?` | Shortcut list |
